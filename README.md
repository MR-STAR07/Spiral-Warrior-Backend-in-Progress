# Spiral Warrior Backend — In Progress

An unofficial community project exploring the reconstruction of a local backend for the discontinued mobile game Spiral Warrior.

## Project status

This project is experimental and incomplete. It is **not the original official game server**, and some features are simulated or only partially implemented.

## What's included?

The `backend_distribution/` directory contains the standalone backend package, setup instructions, source code, and regression tests.

## Running locally

See [`backend_distribution/README.md`](backend_distribution/README.md) for setup instructions and requirements.

The backend is intended for local-network testing and is not production-ready.

This is an unofficial community preservation and research project. It is not affiliated with the original developers or publisher. Rights to third-party game assets and data remain with their respective owners.
